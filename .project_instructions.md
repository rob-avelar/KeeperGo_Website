# KeeperGo - Project Instructions

## Overview
KeeperGo is a goalkeeper rental platform for the Netherlands. Organizers can hire goalkeepers for amateur/recreational football matches.

## Deployed At
- Primary: keepergo.abacusai.app
- Custom domain: keepergo.nl

## Theme & Visual Style
- **Dark theme**: gray-950 background
- **Accent color**: lime-400 (neon green)
- **Cards/surfaces**: bg-gray-900 with border-gray-800
- **Text**: gray-100 (headings), gray-300 (body), gray-400 (muted)
- **Buttons**: bg-lime-400 text-gray-950 for primary CTAs
- **Font**: Default Next.js font stack

## User Communication
- User communicates in **Portuguese (Brazilian)**
- Respond in Portuguese when talking to user

## Architecture
- NextAuth.js with JWT strategy + PrismaAdapter
- Dual-role support: same email can be ORGANIZER + GOALKEEPER
- `/api/switch-role` endpoint toggles active role in DB
- Dashboard pages auto-switch role when accessed
- Middleware: auth-only check (no role enforcement except admin)
- Stripe Connect for goalkeeper payouts (test mode)
- Google SSO configured
- Google Analytics configured (placeholder ID)
- Beta invite system (currently disabled)

## Key Design Decisions
- Header pattern: Logo left, actions right, h-16, max-w-7xl container
- Back button: variant="outline" size="sm" with ArrowLeft icon, positioned right
- Role switch buttons in dashboard headers with ArrowLeftRight icon
- Landing page auto-redirects logged-in users to their dashboard
